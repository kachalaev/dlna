# dlna

Сайт-каталог для просмотра видеоархива в локальной сети. Сервер работает на Mac Intel с macOS Big Sur, диски подключены к нему. С других компьютеров и телефонов в той же сети архив открывается в браузере.

## Как это видит зритель

Папки с разных томов показаны одним деревом. Имена дисков не отображаются. Если на разных томах совпадает путь папки, файлы из них собираются в одну папку.

Форматы: MP4, MKV и AVI, высокое качество. MP4 воспроизводится напрямую. MKV перепаковывается без перекодирования, картинка и звук не меняются. AVI показывается в каталоге; на лету он не конвертируется.

## Обновление каталога

Новые файлы попадают в каталог при периодическом сканировании и по кнопке обновления. Повторный обход читает заново только новые и изменённые файлы. Если том не подключён, уже известные записи с него не удаляются.

Первый том — `lib2`, путь `/Volumes/lib2`.

## Стек

Python, FastAPI, SQLite и ffmpeg. Архив только читается, файлы на дисках не изменяются.

## Запуск на Mac

Нужны Python 3.12 с python.org, а также `ffmpeg` и `ffprobe` в `PATH`. Сервер запускается из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
python -m app
```

В `config.yaml` путь тома уже указан как `/Volumes/lib2`. Другой диск добавляется ещё одним элементом в `volumes` и следующим сканированием.

Сайт слушает порт 8080 на всех интерфейсах. С другого компьютера в той же сети его открывают по адресу `http://<ip-mac>:8080`. Mac не должен засыпать, пока им пользуются, а диски должны оставаться подключёнными.

Первый обход читает длительность каждого файла и поэтому дольше следующих: повторно разбираются только новые и изменённые. Кнопка «Обновить каталог» запускает обход сразу, не дожидаясь интервала в 15 минут.
